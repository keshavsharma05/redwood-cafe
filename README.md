## 📋 Overview

Redwood Café is a full-stack café ordering platform that streamlines the ordering experience for customers and simplifies operations for café admins.

Customers can browse the menu, place orders, track their status, and view order history. Admins can manage incoming orders from booking to completion with an intuitive dashboard.

The system is built with a focus on security, scalability, data integrity, and a smooth user experience.

| | |
|---|---|
| 🛍️ **Customer App** — Browse, order & track | ⚙️ **Admin Panel** — Manage orders efficiently |
| 🔒 **Secure API** — Built with Node.js & Express | 🌿 **Database** — MongoDB Atlas |
